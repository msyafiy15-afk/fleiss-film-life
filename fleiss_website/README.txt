FLEISS WEBSITE — SITE GUIDE

START HERE
Open html/index.html. This is the homepage and links to the three main sections.

SITE MAP
- html/cinema/index.html — Cinema & Philosophy.
- html/life/index.html — Life & Reflection.
- html/creativity/index.html — Fleiß & Creativity.

READING PAGES
- Cinema: characters.html, films.html, storytelling.html.
- Life: character matcher.html, film matcher.html, film journal.html, clips-lines.html.
- Creativity: behind the scenes.html, create your story.html, read others story.html.

SHARED FILES
- styles.css contains the design system and responsive layouts.
- script.js contains the film and character matchers, journal and story storage in localStorage, and quote filtering.

PRIVACY AND HOSTING
Journal entries and stories are stored in localStorage in the current browser on this device. Stories published through this static site are only visible in that browser; they are not shared with other visitors. There is no account system or server-side storage. Browser data can be cleared by the user or browser.
